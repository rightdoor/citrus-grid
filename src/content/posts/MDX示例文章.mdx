# 用 MDX 写文章

本篇演示 `src/content/posts` 目录下的 `.mdx` 文章支持：在 Markdown 的基础上，可以书写 JSX、引用组件、执行表达式。站点原有的数学公式、代码高亮、脚注、提示容器等能力在 MDX 中同样可用 :tada:

> `.mdx` 与 `.md` 走同一条自定义 unified 处理管线，区别只是前端多了一层 MDX 编译。

## 1. 普通 Markdown 语法照常可用

### 列表

- 无序列表第二项

### 表格

| 能力 | Markdown | MDX |
| --- | --- | --- |
| 表达式 | 不支持 | 支持 |
| 组件导入 | 不支持 | 支持 |
| 数学公式 / 脚注 / 容器 | 支持 | 支持 |

### 代码

```ts
// 代码块照样有高亮和复制按钮
export const greet = (name: string) => `你好，${name}`
```

行内代码 `const answer = 42` 也没有问题。

## 2. 表达式与变量

借助 `export` 定义变量，再在正文的 `{...}` 花括号中直接使用：

当前年份是 {year}，本篇关键词共 {highlights.length} 个：

<ul>
  {highlights.map((item) => (
    <li key={item}>{item}</li>
  ))}
</ul>

也可以写任意 JavaScript 表达式，例如 2 的 10 次方等于 {2 ** 10}。

<Callout type="tip" title="小知识">

花括号 `{}` 在 MDX 中是表达式语法，写普通文本时需要用反引号包裹（如上面的 `{}`），或写成转义形式 `\{`。

</Callout>

## 5. 小结

把 `.md` 改名为 `.mdx` 不会破坏任何既有语法，在此之上还能使用表达式与组件。更多基础语法可以参考 [Markdown 语法样例](./Markdown语法样例.md)，其中的相对链接会被自动解析为站内地址 :rocket:
